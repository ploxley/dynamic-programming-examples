# Dynamic programming examples in LISP Scheme
The purpose of this repository is to show how to apply the dynamic programming algorithm in Scheme using standard SICP idioms. There are currently only two examples, one stochastic (inventory control) and one deterministic (knapsack), but they give the general idea. 

To run this code requires `Racket`, although it should also run under most LISP Scheme implementations with few modifications. Download a snapshot of the repository's files as a zip file to your local computer, and then unpack the zip file. Type `(enter! "run_model.scm")` on the command line of the interpreter (REPL) to run the model. Either of the examples can be selected by commenting-out, and un-commenting, the appropriate code in `model.scm`.
